#LehroSol's differentiation

  1. Only tool combining a Ralph-style loop engine, a harness/policy verification gate (OWASP-scoped), and git-worktree multi-agent orchestration in one package.
  2. Adapter, not replacement: wraps existing agent CLIs (Claude Code, Codex, OpenCode, Hermes Agent, etc. — see 08 · Agent Adapters) via MCP instead of competing with them.
  3. One control plane, two front ends: the same MCP endpoint drives the terminal and a GUI dashboard, enabling mid-task handoff either direction.
  4. Zero-dependency core for instant npm i -g / bunx / curl | bash installs.
  5. Apache-2.0 (since 3.2.0, ADR-0012): permissive redistribution with attribution plus an explicit patent grant, so embedders can vendor LehroSol in proprietary products and CI images without a copyleft/license-compatibility review.
  6. Agent-agnostic instruction files: ships dedicated entry points for every major agent CLI (AGENTS.md, CLAUDE.md, GEMINI.md — see 09 · Agents & Skills Map) instead of assuming one vendor's agent.
