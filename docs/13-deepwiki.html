#Glossary

TermMeaning
Loop engineeringThe Ralph-style outer loop that repeatedly invokes an adapter and grades the result. See 03.
Harness engineeringThe policy + OWASP verification gate every iteration/worker must clear. See 04.
Orchestration engineeringParallel, isolated multi-agent execution via git worktrees + a recovery supervisor. See 05.
AdapterA thin, execFile-based wrapper around one external agent CLI, conforming to one shared contract. See 08.
Score AgentThe grading step (src/loop/scoreAgent.js) that turns a harness evaluation into a loop verdict (continue / stop-success / stop-budget-exhausted).
Capability tierfrontier / standard / small / local — which pass bar an adapter's output is held to.
OWASP scopeWhich rule pack(s) apply to a policy evaluation: llm, web, asvs.
WorktreeAn isolated git working directory + branch created by git worktree add, sharing the main repo's .git object store.
Session / checkpointA loop run's persisted record (~/.lehro/sessions.sqlite) and its per-iteration snapshots.
Control planeThe single MCP JSON-RPC tool registry (src/mcp/tools.js) every surface (CLI, GUI, external agent) calls into.
Terminal UI layerThe ANSI-based, zero-dependency rich CLI output system in src/core/ui.js (banner, boxes, tables, spinners, progress bars, interactive wizard). See ADR-0010.
Interactive modelehrosol -i / --interactive — a guided wizard using node:readline for prompt/select/confirm flows, an alternative to memorizing CLI flags.
Terminal GUI / TUIlehrosol tui — a dashboard inside the terminal with system health, adapter, session, policy, orchestration, and quick-action panels.
SkillA short, task-scoped workflow .md under docs/skills/. See 09.

#Module-by-module reference

#bin/

FilePurpose
bin/lehrosol.jsCLI entrypoint; zero-dependency argument parsing, dispatches to src/commands/*. Shows themed banner and compact help via src/core/ui.js. Supports -i/--interactive wizard mode and tui terminal GUI mode. Published as both the lehrosol and lehr-sol bins.

#src/core/ — shared primitives, dependency-free

FilePurpose
config.jsResolves LEHRO_HOME (~/.lehro), CONFIG_PATH, CHECKPOINTS_DIR, SESSIONS_DB, and the worktree registry path.
pathSafety.jsGuards against unsafe path escapes; never weaken silently (see AGENTS.md).
sessionStore.jsnode:sqlite-backed session/checkpoint persistence with a JSON-file fallback.
logger.jsMinimal dependency-free logger with --json / --quiet / --no-color awareness; ANSI codes built from char(27).
ui.js~360-line rich terminal UI layer — banner, Unicode box drawing, themed tables, progress bars, step indicators, status messages ([OK]/[INFO]/[WARN]/[ERROR]), dividers, section headers, next-steps guidance, code blocks, a CI-safe zero-dependency spinner (braille frames), and interactive wizard mode (-i/--interactive) using node:readline. Themed to match the GUI's dark glass-HUD palette. See ADR-0010.
index.jsPackage main entry, re-exports core primitives for programmatic use.

#src/mcp/ — the control plane

FilePurpose
tools.jsTOOL_DEFINITIONS — the 9-tool self-documenting registry (doctor_check, policy_evaluate, loop_run, adapters_list, sessions_list, sessions_show, orchestrate_spawn, orchestrate_list, orchestrate_remove).
server.jsJSON-RPC 2.0 server; stdio transport for agent CLIs, HTTP transport (default :4177) for the GUI/remote clients. See 06.

#src/harness/ — the verification gate

FilePurpose
policy.jsPOLICY_RULES, evaluatePolicy(), capability-tier pass bars, scoring/banding logic.
owasp.jsOWASP_SCOPES rule-pack definitions (llm/web/asvs) and scanOwaspBasics(), the real file-content heuristic scanner. See 04.

#src/loop/ — the Ralph-style engine

FilePurpose
loop.jsThe iteration state machine: create session → invoke adapter → scan → score → checkpoint → continue/stop.
scoreAgent.jsTurns a harness evaluation into a loop verdict against the selected capability tier.
agentMd.jsreadAgentMd() — loads the target repo's AGENTS.md/AGENT.md/CLAUDE.md/GEMINI.md into loop context.
fixPlan.js (referenced by loop.js)Reads/appends fix_plan.md entries between iterations and across sessions.
adapters/index.jsThe ADAPTERS registry mapping adapter ids to implementations.
adapters/makeCliAdapter.jsShared factory every real adapter is built from.
adapters/shared.jsInstallation detection + git diff-based changedFiles/policyInput derivation, shared across adapters.
adapters/claudeCode.js, codex.js, opencode.js, geminiCli.js, aider.js, goose.js, hermesAgent.jsThe 7 real adapters. See 08 and docs/claude/AGENTS.md for the Claude-specific deep dive.
adapters/local.jsAlways-available dry-run/demo adapter; no external process.

#src/orchestrator/ — multi-agent supervision

FilePurpose
worktree.jsspawnWorktree()/listWorktrees()/removeWorktree() over real git worktree commands; auto-detects the base branch (see ADR-0008).
supervisor.jsRetry / replan / decompose / escalate recovery strategies for stalled or repeatedly-failing workers. See 05.

#src/commands/ — CLI wiring (all upgraded with rich UI from src/core/ui.js)

FilePurpose
doctorLogic.jsEnvironment/health checks backing lehrosol doctor and the doctor_check MCP tool.
doctor.jsWires doctor output through ui.table() + ui.success()/ui.warning() with next-steps guidance.
init.jsWires lehrosol init with a planned-files table, created/skipped summary, and next-steps guidance.
loop.jsWires lehrosol loop run with config table, spinner, per-iteration progress bars, score/bar/verdict display, warnings, and session summary.
policy.jsWires lehrosol policy evaluate with config table, spinner, visual score bar with band/verdict, and numbered violation/warning lists.
orchestrate.jsWires lehrosol orchestrate spawn/list/remove with config tables, spinners, worker tables, and feedback.
sessions.jsWires lehrosol sessions list/show with themed session tables and checkpoint detail views.
adapters.jsWires lehrosol adapters with ID/label/binary/status table and installed/not-found highlighting.
mcp.jsWires lehrosol mcp start with themed stdio/HTTP startup messages.
gui.jsWires lehrosol gui with themed startup, tool listing, and next-steps guidance.
tui.jsWires lehrosol tui — the in-terminal graphical dashboard with basic/intermediate/advanced modes, dashboard panels, quick actions, interactive menu, and JSON snapshot mode. See 15 · Terminal GUI.

#gui/ — the one npm-dependent surface

PathPurpose
gui/src/App.jsxTab shell wiring together all six panels.
gui/src/components/*Panel.jsxDoctor, Loop, Adapters, Sessions, Orchestrate, Policy panels — each calls one MCP tool.
gui/src/lib/rpcClient.jsThin fetch-based JSON-RPC client used by every panel.
gui/src/styles.css, gui/tailwind.config.jsThe dark glass-HUD design tokens, reused by this doc site's .html output and the terminal UI layer's color palette.

#docs/ — this doc site

PathPurpose
docs/tools/build-docs.mjsDependency-free generator producing .json/.html counterparts for every .md under docs/. See ADR-0009.
docs/skills/*.skill.mdTask-scoped workflow guides. See 09.
docs/claude/AGENTS.mdClaude-Code-specific deep dive.

#Repo-root agent files

FilePurpose
AGENTS.mdCanonical rules — read natively by Codex CLI and OpenCode; also the seed context the Loop Engine feeds itself.
CLAUDE.mdThin pointer, auto-loaded by Claude Code.
GEMINI.mdThin pointer, auto-loaded by Gemini CLI.
fix_plan.mdThe Loop Engine's running queue of known issues, read and appended every iteration.
